# Label Browser window

**Extras > Label Browser**

Browses project assets by their **asset labels** (the tags set at the bottom of the Inspector). Pick a
label on the left and every asset carrying it is listed on the right.

## Example

Label `Boss` on three prefabs and a music clip. Select **Boss** in the sidebar and the four assets
appear; drag them straight into a scene or an object field.

## Use

- **Sidebar:** every label in use, plus **All**. Right-click a label for **Delete Label**, which removes
  it from every asset after a confirmation.
- **Asset list:** the assets with the selected label. Double-click one to open it. Select several and
  drag them anywhere Unity accepts assets.
- **Search** filters the assets by name. **Refresh** (also on right-click) rescans the project.

When the window is narrower than 250 pixels it switches to a compact layout with the labels folded
above their assets, so it fits in a side dock.
